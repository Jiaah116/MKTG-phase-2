# TeamFit Phase 2: Teammate Testing Guide

We’re asking for two things: try the manual and TeamFit workflows, then review our demo slides. Please do the test before looking at the slides so the walkthrough doesn’t give away what to do.

## Materials for this test

- [TeamFit public demo](https://teamfit-phase-2-prototype.vercel.app)
- [Local setup instructions](../README.md), if the organizer asks you to run TeamFit locally
- Client request, staffing table, and manual checklist: **To be shared by the test organizer.**
- Case assignments and testing order: **To be shared by the test organizer.**
- Response form or feedback template: **To be shared by the test organizer.**
- Demo slides: **To be shared by the test organizer.**

Do not use real client or employee information. Use only the fictional information supplied for this test.

## 1. Compare the manual process and TeamFit

Imagine you’re an agency manager who just received an additional client request. Your job is to decide what the agency should do next and what still needs to be checked before anyone makes a commitment to the client.

Use the cases and order assigned by the test organizer. You’ll use the client request, staffing table, and checklist for the manual condition, and TeamFit with equivalent source information for the other condition. Use only the fictional information provided. If something is missing, record what you would verify instead of making up an answer.

For each run, start the timer when you first open the case. Stop when you’ve checked your work, made any corrections, and recorded your final decision. Include any time spent checking or correcting the tool’s output. If you get stuck, note where. If you receive help, record what it was.

Please return the following for each run:

- Case ID and method used (manual or TeamFit)
- Total time, including checking and corrections
- Your decision, the reason, and the next action you would take
- What still needs confirmation, if anything
- Anything confusing, anything you corrected, and any help you received

If the organizer also assigns a workload update, record that time separately and note whether you had to enter the same information twice.

## 2. Review the demo slides after testing

The demo shows two requests: a spring launch graphics request with missing information, and a complete request that can proceed to a capacity check.

After reviewing the slides, please answer three questions:

1. In the first case, was it clear what the client needed to answer, what the agency needed to check internally, and why the request was held?
2. In the second case, was it clear that a potential candidate still needed manager review and that the agency had not accepted the request?
3. Which slide or step was hardest to follow, and what one change would make it clearer?

## How to send your feedback

Send the test results and slide feedback to the test organizer using the team’s agreed channel. Please use only fictional data in the demo and in your notes.
